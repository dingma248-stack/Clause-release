Hand it a folder.把文件夹交给它。

Link a project folder and Clause reads, searches and edits the files in it, runs your scripts and shows you exactly what changed. You decide how much it does on its own: ask before every change, only before risky ones, or never. 绑定项目文件夹后，Clause 能读取、搜索和修改里面的文件，运行你的脚本，并把每一处改动清楚地列给你。放手多少由你决定：每次修改都先问、只在有风险时问，或者完全放手。

  • Every change is backed up and can be undone每一处改动都有备份，可以撤销
  • Runs commands in PowerShell only if you switch them on只有你打开开关，才会运行 PowerShell 命令
  • Reads PDF, Word, Excel and PowerPoint files能读 PDF、Word、Excel 和 PowerPoint

Split the big jobs.大活儿，拆开干。

When a task has parts, Clause starts sub-agents that work side by side, up to twenty at once, each with its own context, and brings their reports together. Longer jobs can run as workflows in the background while you keep talking. 任务能拆开时，Clause 会派出子智能体同时开工，最多二十个，各自有独立的上下文，最后把报告汇总给你。更长的任务可以写成工作流，在后台跑，你接着聊别的。

Make the deck.直接出 PPT。

Ask for slides and Clause designs a PowerPoint you can edit: titles, charts, tables, equations and speaker notes. Send it a template or a slide you like and it follows the look. Open the file in PowerPoint, WPS or Keynote and keep going. 说一句要做 PPT，Clause 就会设计一份能编辑的 PowerPoint：标题、图表、表格、公式、演讲备注都有。发给它一个模板或者你喜欢的页面，它会照着那个样子做。用 PowerPoint、WPS 或 Keynote 打开就能接着改。

Pick the model for the job.按任务挑模型。

Reason with DeepSeek, write in Chinese with Qwen or Kimi, code with GPT or Claude, and keep private notes on a model that runs on your own PC. Switch in the middle of a conversation; Clause remembers how hard each model should think. 推理用 DeepSeek，写中文用通义千问或 Kimi，写代码用 GPT 或 Claude，私密的内容交给你电脑上的本地模型。对话进行到一半也能换模型；每个模型想得多深，Clause 都会替你记着。

Questions常见问题

Does Clause cost anything?Clause 收费吗？

No. Clause itself is free. When you use a model in the cloud, you pay its provider directly through your own API key. Models on your PC cost nothing to run.不收费。用云端模型时，费用通过你自己的 API Key 直接付给模型服务商；在自己电脑上跑模型不花钱。

Which models can I use?能用哪些模型？

DeepSeek, Qwen, Kimi, Zhipu GLM, SiliconFlow, Volcengine Ark, OpenAI, Anthropic and OpenRouter are set up for you; any other OpenAI-compatible service works too. On your PC, Clause runs Strata’s 125B model and any model you run with Ollama.DeepSeek、通义千问、Kimi、智谱 GLM、硅基流动、火山方舟、OpenAI、Anthropic 和 OpenRouter 都已经预设好，其他兼容 OpenAI 接口的服务也能接。本地方面，Clause 能运行 Strata 的 125B 模型，以及你用 Ollama 运行的任何模型。

What does my PC need?对电脑有什么要求？

For cloud models, any PC with 64-bit Windows 10 or 11. To run the 125B model locally you need 48 GB of RAM (32 GB for the Coder size) and an NVIDIA RTX 20-series or newer, or a recent AMD graphics card.用云端模型，64 位 Windows 10 或 11 就行。要在本地跑 125B 模型，需要 48 GB 内存（Coder 版 32 GB），以及 NVIDIA RTX 20 系或更新的显卡，或较新的 AMD 显卡。

Where are my chats and keys kept?对话和密钥存在哪里？

On your PC, in Clause’s own folder. There is no account and no Clause server. Model requests go straight from your computer to the provider you picked.都在你的电脑上，Clause 自己的文件夹里。没有账号，也没有 Clause 的服务器，模型请求直接从你的电脑发给你选的服务商。

Windows warns me when I open the installer. Is that expected?打开安装包时 Windows 弹出警告，正常吗？

Yes. Windows SmartScreen shows “Windows protected your PC” for apps without a paid code-signing certificate. Click More info, then Run anyway.正常。没有付费代码签名证书的软件，Windows SmartScreen 都会提示“Windows 已保护你的电脑”。点“更多信息”，再点“仍要运行”即可。

How do updates work?怎么更新？

Clause looks for new versions in the background and installs them the next time you quit. You can turn this off in Settings.Clause 会在后台检查新版本，在你下次退出时自动装好。不想自动更新可以在设置里关掉。

Is there a Mac or Linux version?有 Mac 或 Linux 版吗？

Not yet. Clause is for 64-bit Windows 10 and 11.暂时没有。Clause 目前支持 64 位的 Windows 10 和 11。
